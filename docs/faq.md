# Frequently Asked Questions

## General

**Q: Why Intent?**
A: Discord is forcing government ID verification. We're building a privacy-first alternative.

**Q: Is Intent ready to use?**
A: Not yet. Active development in Phase 1 MVP.

**Q: Can I self-host?**
A: Yes, via Docker images (in development).

## Development

**Q: How do I contribute?**
A: See [CONTRIBUTING.md](../CONTRIBUTING.md)

**Q: Where's the server code?**
A: Server is proprietary. Clients, SDKs, and protocol specs are open source.

**Q: Can I build a third-party client?**
A: Yes! See [intent-protocol](https://github.com/IntentAi/intent-protocol)
